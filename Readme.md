# 🧠 Quiz Master - GK & Coding Game

A fun Python Quiz Game with GK + Coding questions, score tracking and shuffling. Learn while you play! Made in Pydroid 3.

### ✨ Features
- 5 Amazing Questions (GK + Tech + Your Robot)
- 3 Options MCQ
- Random Shuffle Every Time
- Score Tracking
- Final Result with Comments
- 100% Offline

### 🛠️ Tech
- Python 3
- random, time

### 🚀 How to Run
Pydroid 3 > Create quiz_master.py > Paste > Run
